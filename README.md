# Blogicum

A small blog project for learning. It shows posts and simple pages. This repository is written mostly in Python with some HTML templates.

## Features
- blog posts
- simple pages
- basic layout and templates

## Requirements
- Python 3.10+ (or newer)

## How to run (example)
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python manage.py runserver
```

## Project structure
- `blogicum/` — Python application code
- `templates/` — HTML templates
